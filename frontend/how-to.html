1. Start here: open a tool

  1. On the home page, press Let’s start calculating.
  2. The calculator workspace opens. The tool list is on the left. On a phone, press the ☰ menu at the top to open it.
  3. Choose the tool you need. The selected tool appears in the large workspace on the right.
  4. Enter the values or expression shown in that tool, then press its calculate button.
  5. Read the result panel and the status message. If an input is invalid, the status message should explain what needs correcting.

The sidebar also has How to use · Instructions. It opens this guide in a new tab, so you can keep the calculator open while following the steps.

2. Scientific Calculator

Use this for arithmetic, powers, roots, trigonometry and common scientific functions.

  1. Choose Scientific Calculator in the sidebar.
  2. Type an expression in the Expression field. Use * for multiplication, / for division, ^ for powers and parentheses to group operations.
  3. Choose DEG when your angle is in degrees, or RAD when it is in radians.
  4. Press Calculate. The result appears in the Result panel.

Example A — trigonometry

Set the angle mode to DEG. Enter sin(30).

Expected result: 0.5

Example B — powers and roots

Enter sqrt(144) + 2^3.

Expected result: 20

If a trigonometric answer looks unexpected, check DEG/RAD first. The same angle has different numeric values in degrees and radians.

3. Equations

Use this tool when you want to solve an equation, not just evaluate an expression.

  1. Choose Equations from the sidebar.
  2. Choose the equation type. For a quadratic, select the quadratic option; for a relation involving x and y, use the suitable multivariable option.
  3. Enter the complete equation, including the equals sign.
  4. Press Calculate. Read the roots or solution returned in the result panel.

Example — solve a quadratic

Choose the quadratic equation mode and enter x^2 - 5*x + 6 = 0.

Expected roots: x = 2 and x = 3

For a relation such as y^2 = 4*x, use the graphing capability in Advanced Maths Studio to see the curve. This relation is a sideways parabola.

4. Advanced Maths Studio: what is inside?

Open Advanced Maths Studio from the calculator sidebar. It is a collection of connected mathematical workspaces. Use the tabs at the top to move between them.

Calculator

Evaluate a quick scientific expression without leaving the Studio.

Graphing Calculator

Plot functions, equations and relations; compare curves and inspect values.

Spreadsheet

Enter data, calculate with cell formulas, import/export CSV and fit a trend line.

Symbolic CAS

Differentiate, integrate, evaluate limits and solve supported equations.

Geometry

Place points and construct lines, circles, midpoints, angles and polygons.

3D Surface

Plot z=f(x,y) as a rotatable wireframe surface.

Statistics & Probability

Calculate descriptive statistics, event probabilities and counting results.

There is no longer a tab redundantly called “Advanced Maths Studio” inside the Studio. The graphing tab is named Graphing Calculator.

5. Calculator inside Advanced Maths Studio

  1. Open the Studio and choose the Calculator tab.
  2. Enter an expression in the input field.
  3. Press Calculate or press Enter.
  4. The answer appears below the input. Use Clear to start another calculation.

Try this

Enter sin(pi/2) + sqrt(25).

Expected result: 6

This compact Studio calculator uses radians for trigonometric functions. Use pi/2 to represent 90 degrees.

6. Graphing Calculator

This is the Studio’s main graphing workspace. It supports Cartesian, parametric, polar and implicit relations.

A. Plot an ordinary function

  1. Choose Graphing Calculator.
  2. Keep Graph type set to Cartesian y = f(x).
  3. In the expression box, enter x^2.
  4. Press Plot graphs. You should see a U-shaped parabola.

Try a second curve

Press + Add function, enter sin(x), then press Plot graphs. Both curves should appear together in different colours.

B. Plot an equation with an equals sign

  1. In Cartesian mode, enter y^2 = 4*x.
  2. Press Plot graphs.
  3. The Studio treats an equation involving y as an implicit relation and draws its curve.

Expected shape: a sideways parabola opening to the right, with its vertex at (0, 0).

C. Change the view and inspect values

  • Set X minimum/maximum and Y minimum/maximum to control the visible area.
  • Drag the graph to pan. Use the mouse wheel or trackpad to zoom.
  • Enter an x value under Trace x and press Trace curves to read the corresponding y values.
  • Press Find roots, extrema & intersections for numerical estimates.
  • Use Export samples CSV to download sampled points.

D. Use parameters and sliders

  1. Enter a*x^2 as a function.
  2. Under Parameters & sliders, add a parameter named a.
  3. Move the slider. The graph should update as a changes.

E. Other graph types

7. Spreadsheet — a complete worked example

The spreadsheet is useful when you have a small dataset and want formulas, a chart or a trend line. Each cell has a column letter and row number: A1 means column A, row 1.

A. Enter the data

  1. Open the Spreadsheet tab.
  2. Click cell A1 and type Month; click B1 and type Sales.
  3. Enter the following values in the cells shown.

B. Calculate with a formula

  1. Click an empty cell such as B6.
  2. Type =SUM(B2:B5) and press Enter or move away from the cell.
  3. The cell should show the total, 550.
  4. In B7, enter =AVERAGE(B2:B5). The result should be 137.5.

More formulas to try

=MAX(B2:B5) → 180 · =MIN(B2:B5) → 100 · =COUNT(B2:B5) → 4

=B2+B3 adds the values in cells B2 and B3.

C. Make a chart

  1. Set X column to A and Y column to B.
  2. Set Regression to None for just the data points, or Linear fit to add a straight trend line.
  3. Press Plot selected columns. The chart appears below the sheet.
  4. Try Quadratic fit to compare a curved trend line.

D. Import and export

Use Import CSV to load a CSV file. Leave “First row is headers” checked if the first line contains column names. Use Export CSV to download the sheet. You can add rows and columns with the + buttons.

The current sheet is local to the open browser tab; it is not automatically saved to a cloud account. Formula support is intentionally limited to the listed functions and arithmetic. Circular references are reported as errors.

8. Symbolic mathematics (CAS)

CAS works with mathematical expressions symbolically instead of only producing a decimal approximation.

  1. Open Symbolic CAS.
  2. Choose an operation and the variable.
  3. Enter the expression without an equals sign for calculus operations.
  4. Fill in extra fields if they appear, then press Calculate symbolically.
OperationEnterExpected result
Derivativex^33*x^2
Indefinite integral2*xx^2 plus a constant
Definite integralx, bounds 0 and 22
Limitsin(x)/x, point 01

For Solve equation in x, choose that operation and enter an equation such as x^2 - 4 = 0. The variable selector is hidden because this solver is specifically for x.

Some expressions do not have a simple closed-form result or may not be supported. If the engine reports an error, try a simpler equivalent expression.

9. Dynamic Geometry

  1. Open the Geometry tab. Choose Point in the Tool menu.
  2. Click the canvas twice to create points A and B.
  3. Choose Segment, then click A and B to connect them.
  4. Choose Move point and drag A. The segment should follow the point.
  5. Choose Circle, then select a centre point and a second point on the circumference.
  6. Choose Midpoint, then select two points to create their midpoint.

Try measuring a distance

Create two points, choose Distance, and select both points. The status line reports the distance in coordinate units.

For a polygon, choose Polygon, select at least three vertices, then press Finish polygon. Use Undo last to undo the latest pending selection or construction; Clear construction resets the canvas.

10. 3D Surface Plotter

  1. Open 3D Surface.
  2. In the expression field, enter x^2+y^2 for z=f(x,y).
  3. Keep the default X and Y ranges, then press Plot 3D surface.
  4. You should see a bowl-shaped wireframe. Change Horizontal rotation, Vertical rotation and Zoom to inspect it.
  5. Press Reset 3D view to restore the default camera settings.

Try a saddle surface

Replace the expression with x^2-y^2 and plot again.

Expected shape: a saddle surface.

This is a sampled wireframe view, not a full 3D modelling system. Undefined regions may appear as gaps.

11. Statistics

  1. Open Statistics & Probability.
  2. In Data values, enter 2, 4, 4, 6, 9.
  3. Choose Mean and press Calculate statistic.
  4. Change the selection to Median, Mode, Range, Variance or Standard deviation and calculate again.

Check your result

For 2, 4, 4, 6, 9, the mean is 5, the median is 4, the mode is 4, and the range is 7.

Sample variance and population variance are different: sample variance uses n−1 in the denominator; population variance uses n.

12. Probability & Counting

In the Probability & counting panel, select an operation. The fields change to match that operation.

Simple probability

Choose Simple probability. Enter Favorable outcomes = 2 and Total outcomes = 6. Press Calculate probability.

Expected result: 1/3 (approximately 0.3333)

Combination

Choose Combination nCr. Enter n = 5 and r = 2.

Expected result: 10 ways

Binomial probability

Choose Binomial probability. For example, enter n = 5, k = 2, p = 0.5 to find the probability of exactly two successes in five independent trials.

Expected result: 0.3125

For Conditional probability, enter P(B) and P(A and B). For Union probability, enter P(A), P(B), and P(A and B). All probability values must be between 0 and 1.

14. Save and reopen your Studio work

  1. In Advanced Maths Studio, press Save workspace. A JSON file downloads to your device.
  2. Keep the file somewhere you can find it later.
  3. To restore it, open the Studio and press Open workspace.
  4. Select the JSON file you saved. The Studio restores the supported graph, spreadsheet, CAS, statistics, probability and surface settings/data.
Workspace files are local downloads. They are not synced to an online account. The geometry construction and the Studio calculator's recent expression are not currently part of the saved workspace.

15. Troubleshooting and getting help

  • Nothing happens: check that the correct tab is selected and that you pressed the action button.
  • Expression error: check parentheses, operators and variable names. Use * for multiplication, such as 4*x.
  • Graph not visible: check X/Y ranges and confirm the curve lies inside the visible area. Press Reset view to return to the default range.
  • Formula error in the sheet: confirm the referenced cells contain numbers and the formula begins with =.
  • API offline or request timed out: the server may be waking up or temporarily unavailable. Wait a moment and retry.
  • On mobile: use the menu button to reopen the sidebar; in Studio, scroll the tab row horizontally if needed.

To report a bug, use Share feedback. Include the tool name, the exact input you entered, what you expected, and what appeared instead. Do not include passwords or private information.
