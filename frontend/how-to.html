1. Getting started

The main page introduces the project. The calculator itself opens in the workspace below it.

  1. On the home page, select Let’s start calculating.
  2. The calculator workspace opens. On a phone, use the ☰ menu to show or hide the tool list.
  3. Choose a calculator from the left sidebar. Its controls appear in the main workspace.
  4. Enter values or expressions, choose any required options, and press the relevant calculate button.
  5. Read the result and any status message shown below the controls.
Advanced Maths Studio is opened from the calculator’s sidebar. It is not a separate item in the home-page navigation.

2. Scientific Calculator

Use this for arithmetic, scientific notation, and common mathematical functions.

  1. Choose Scientific Calculator in the sidebar.
  2. Enter an expression in the input area using numbers, operators, and supported functions.
  3. Check the angle selector: choose DEG for degrees or RAD for radians before trigonometric calculations.
  4. Run the calculation and inspect the displayed answer.

Examples to try:

sin(30) with DEG selected → 0.5sqrt(144) + 2^3 → 20
Use parentheses to make the order of operations clear. Trigonometric answers depend on the selected angle unit.

3. Equations

Use the Equations tool to solve supported polynomial equations and inspect roots. Enter the equation in the format requested by the form, then run the solver. For example, try x^2 - 5*x + 6 = 0.

If you want to see a relationship as a graph rather than only solve it, use the relation/graph option when it is available in the Equations workspace, or use Advanced Maths Studio for more graph controls.

4. Advanced Maths Studio

Open it from the main calculator sidebar. It brings several specialist workspaces together under one interface.

Graphing

Plot functions and compare multiple expressions on one coordinate plane.

Spreadsheet

Enter data, use formulas and ranges, and create charts from your table.

Symbolic CAS

Differentiate, integrate, evaluate limits, and solve supported equations symbolically.

Dynamic geometry

Create and manipulate points, lines, circles, and geometric constructions.

3D surface plotter

Plot a surface defined by z as a function of x and y, then rotate the view.

Statistics & probability

Calculate descriptive statistics and solve common probability/counting problems.

Use the tabs at the top of the Studio to switch between these workspaces. The first tab is the graphing workspace.

5. Graphing, parameters & analysis

  1. In the Studio graphing view, choose a graph type: Cartesian, Parametric, Polar, or Implicit.
  2. Enter an expression. For Cartesian graphs, use x as the independent variable; for parametric graphs use t; polar expressions use θ as the angle variable; implicit graphs describe a relation in x and y.
  3. Use + Add function to compare more than one expression, then choose Plot graphs.
  4. Set the X and Y minimum/maximum values to change the visible range. Use Reset view to return to a standard view.
  5. To make an expression adjustable, include a parameter such as a or k, add that parameter under Parameters & sliders, and move its slider.
  6. Enter an X value and select Trace curves to inspect points on plotted curves. Use Find roots, extrema & intersections for numerical estimates.
  7. Use Export samples CSV to export sampled graph values.
y = a*x^2 (Cartesian), then add parameter a. Change the slider to see the parabola update.
Roots, extrema, and intersections are numerical/sample-based estimates. They are useful for exploration, but are not guaranteed symbolic proofs or exact answers.

6. Spreadsheet

  1. Open the Spreadsheet tab.
  2. Tap a cell and enter a number or formula. Formulas begin with =.
  3. Use cell references such as =A1+B1, or ranges such as =SUM(A1:A5).
  4. Supported formula tools include arithmetic, cell references/ranges, SUM, AVERAGE/AVG, MIN, MAX, COUNT, ABS, SQRT, and ROUND.
  5. Use the chart controls to make a chart from your spreadsheet data.
Example: enter 4 in A1, 6 in A2, then =AVERAGE(A1:A2) in another cell. The result is 5.
A formula that refers back to itself, directly or indirectly, is a circular reference and cannot be calculated.

7. Symbolic mathematics (CAS)

Use the Symbolic CAS tab to select an operation, variable, and expression.

  • Derivative: choose the derivative operation and set the order if needed.
  • Indefinite integral: find an antiderivative with respect to the selected variable.
  • Definite integral: provide lower and upper bounds.
  • Limit: enter the point and choose a two-sided, left-hand, or right-hand direction.
  • Solve equation: enter an equation and select the variable to solve for.
Expression: x^2 · Operation: Derivative · Variable: x → 2*x
Symbolic systems support particular mathematical forms. If an expression is unsupported or ambiguous, simplify it and try again; do not assume every possible expression has a closed-form result.

8. Dynamic geometry

  1. Open the Geometry tab and select a tool from the Tool menu.
  2. Choose Point, then tap/click the canvas to place points.
  3. Choose a construction such as Segment, Line, or Circle, then select the required points on the canvas.
  4. Use Move point to reposition a point and see connected constructions update.
  5. Other available constructions include midpoint, perpendicular bisector, parallel/perpendicular lines, distance, angle, and polygon.
  6. Use Finish polygon, Undo last, or Clear construction when appropriate.
The status text below the canvas tells you what the selected tool expects next.

9. 3D surface plotter

  1. Open 3D Surface.
  2. Enter a formula for z = f(x,y), for example x^2+y^2.
  3. Set the X, Y, and Z minimum/maximum ranges.
  4. Select Plot 3D surface.
  5. Adjust horizontal rotation, vertical rotation, and zoom to inspect the wireframe. Select Reset 3D view to restore the default view.
The plot is a sampled wireframe preview. Very large ranges or complex expressions may take longer or show gaps where the expression is undefined.

10. Statistics & probability

Descriptive statistics

  1. Open Statistics & Probability.
  2. Enter comma-separated numeric data, such as 2, 4, 4, 6, 9.
  3. Choose a statistic: mean, median, mode, range, minimum, maximum, variance, standard deviation, or quartiles.
  4. Run the calculation and read the result.

Probability & counting

Choose an operation from the Probability & counting panel: simple probability, complement, conditional probability, union probability, permutation (nPr), combination (nCr), or binomial probability. Fill in the fields that appear for that operation, then calculate.

For probability inputs, use values between 0 and 1 where the field asks for a probability. For counting operations, use valid non-negative whole-number counts.

11. Other calculators

Calculus

Select an operation, enter an expression and variable, add bounds or limit settings if requested, then calculate.

Matrix Calculator

Choose an operation, enter matrix values in the provided fields, and calculate. Available operations include arithmetic, transpose, determinant, inverse, rank, RREF, solving systems, and more.

Statistics

Enter a dataset and select the statistical measure you want to calculate.

Probability & Combinatorics

Choose a probability or counting operation and complete the fields shown for it.

Unit Converter

Choose a conversion category and units, enter a value, and convert. Available categories depend on the connected calculator API.

Finance & Loan EMI

Select simple interest, compound interest, or loan EMI, then provide the principal, rate, and time/term values requested.

Discount & GST

Enter the original price and applicable discount or GST rate to calculate the adjusted amount.

BMI Calculator

Enter height and weight using the available metric or feet/inches inputs, then calculate BMI. BMI is a screening calculation, not a diagnosis.

Date Calculator

Choose add days, subtract days, or date difference, then enter the required date and number of days.

12. Save and load a Studio workspace

In Advanced Maths Studio, use Save workspace to download the current workspace data as a JSON file. Use Open workspace to select a previously saved workspace file and restore it. Keep the file somewhere you can find it again.

A saved workspace file is a data file, not an executable program. Only open workspace files you trust and that were created for this Studio.

13. Tips & troubleshooting

  • Check that you selected the correct tool before entering an expression.
  • Use parentheses to make complicated expressions easier to read.
  • Check DEG/RAD before using trigonometric functions.
  • For graphs, check the graph type, variable names, and visible X/Y ranges.
  • If a tool reports an error, read its status message and simplify the input before retrying.
  • If the API status says offline, the calculator service may be unavailable; try again later.
  • On mobile, open the sidebar using the menu button if the tool list is hidden.

Still stuck or found a bug? Use Share feedback on the home page or the Feedback button in the calculator workspace. Include the tool name, what you entered, what you expected, and your email if you want a reply.
